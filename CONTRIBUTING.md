# Contributing

Issues and pull requests are welcome, especially: real-world dispute scenarios, adapters for open agent-payment standards, and holes in the evidence format.

- Run the tests before opening a pull request: `python -m unittest discover -s tests`.
- Sign off your commits (`git commit -s`) to certify the Developer Certificate of Origin: you wrote the change or have the right to submit it under the Apache License 2.0.
- Keep changes small and explain the reason for them.
